Одинаковый тег у нескольких групп события (например, разных темповых подгрупп одной дистанции) объединяет их в один общий протокол. Оставь пустым, если у группы протокол должен быть отдельный.

Выключи для групп, финиши которых не будут попадать в общий рейтинг бегунов.

Ровный темп — один отрезок. Структурная тренировка (разминка / целевой / заминка, прогрессия) — несколько. Один темп на отрезок — впиши число (5:30). Для прогрессии внутри отрезка — диапазон через дефис (5:40-4:50). Км у отрезка — это и есть план тренировки: сколько километров бежать в каком темпе. Можно оставить пустым, если длину отрезка не фиксируешь — тогда бегун увидит только темп, без разбивки по км.
